============================================================
SEQUENCE DIAGRAM — ZERO-STOCK SMS ALERT
============================================================

PARTICIPANTS:
User
AddItemActivity / EditItemActivity
InventoryViewModel
InventoryRepository
InventoryDao
NotificationsRepository
SharedPreferences
SmsManager
LowStockWorker (WorkManager)

------------------------------------------------------------
USER SETS QUANTITY TO ZERO
------------------------------------------------------------
User → Add/Edit Activity:
    Enter item name + quantity = 0
    Tap Save

Add/Edit Activity → InventoryViewModel:
    insert(item) or update(item)

InventoryViewModel → InventoryRepository:
    repository.insert/update(item)

InventoryRepository → InventoryDao:
    insert/update into Room database

------------------------------------------------------------
CHECK IF SMS SHOULD BE SENT
------------------------------------------------------------
Add/Edit Activity → NotificationsRepository:
    isSmsEnabled()

NotificationsRepository → SharedPreferences:
    read "sms_enabled"

IF disabled → show toast → END

Add/Edit Activity → ContextCompat:
    check SEND_SMS permission

IF denied → show toast → END

Add/Edit Activity → SharedPreferences:
    read "phone_number"

Add/Edit Activity → NotificationsRepository:
    sendSms(number, message)

NotificationsRepository → SmsManager:
    sendTextMessage()

SmsManager → NotificationsRepository:
    SMS sent

Add/Edit Activity:
    show toast "SMS sent"

============================================================
LOGIN SEQUENCE DIAGRAM
============================================================

PARTICIPANTS:
User
MainActivity
SharedPreferences

User → MainActivity:
    Enter username + password
    Tap Login

MainActivity → SharedPreferences:
    read stored username/password

IF match:
    MainActivity → InventoryActivity:
        navigate to inventory screen
ELSE:
    MainActivity:
        show toast "Invalid credentials"

User may tap "Create Account"

MainActivity → SharedPreferences:
    save new username/password

MainActivity:
    show toast "Account created"

============================================================
SAVE PHONE NUMBER SEQUENCE DIAGRAM
============================================================

PARTICIPANTS:
User
NotificationsActivity
SharedPreferences
ImageView (checkmark)

User → NotificationsActivity:
    Types phone number

NotificationsActivity:
    Auto-format number
    Validate 10 digits
    Enable Save button
    Show green checkmark

User → NotificationsActivity:
    Tap Save Number

NotificationsActivity → SharedPreferences:
    save "phone_number"

NotificationsActivity:
    show toast "Phone number saved"
    checkmark persists on reopen

============================================================
LOWSTOCKWORKER SEQUENCE DIAGRAM
============================================================

WorkManager → LowStockWorker:
    doWork()

LowStockWorker → NotificationsRepository:
    isSmsEnabled()

IF disabled → return success

LowStockWorker → ContextCompat:
    check SEND_SMS permission

IF denied → return success

LowStockWorker → InventoryDao:
    getZeroStockItems()

InventoryDao → LowStockWorker:
    return list of zero-stock items

FOR EACH item:
    LowStockWorker → SharedPreferences:
        read "phone_number"

    LowStockWorker → NotificationsRepository:
        sendSms(number, message)

    NotificationsRepository → SmsManager:
        sendTextMessage()

LowStockWorker:
    return Result.success()
